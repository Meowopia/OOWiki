OOChat¶

分类：附属（Extensions）。

OOChat 是喵托邦 / Meowopia 的聊天与社交插件，目标是让服主按自己的玩法组合频道、消息规则和社交体验。

下载前请注意： 当前正式发布版为 v0.1.0，属于基础接入版本，不是完整聊天替代插件，也不是 QQ 界面成品。世界聊天、私聊、历史及可编辑配置的后续版本仍在开发与验收中，尚未正式发布。请勿把下文开发中功能当作 v0.1.0 已提供的功能。

生态分类¶

OOChat 属于附属（Extensions），此分类不等于运行时必须安装 OOEngine。基础运行需要 OOCore；当前正式版不需要 OOEngine，也不提供其窗口界面。

定位与边界¶

能力 当前正式版 v0.1.0
作为服务端插件加载并接入 OOCore 已提供
/oo chat 基础命令入口 已提供；只返回入口提示，不发送聊天消息
世界聊天、私聊、历史查询与撤回 后续版本开发中，不属于本版可用聊天闭环
可编辑频道、冷却和消息长度限制 后续版本开发中
QQ 风格窗口、自定义头像和装扮 尚不可用
好友、公会、城镇、群聊和跨服完整联动 规划中；不能仅凭频道名称推定已对接
邮箱附件、红包、会员及 OO 等级联动 规划中
OOConsole 可视化聊天配置 尚无正式可用工作区；安装 OOConsole 不会解锁上述功能

OOChat 不提供第二套独立网页后台。玩法自定义不能绕过身份、权限、消息状态和数据安全校验。

已实现功能 / Implemented¶

以下仅指已正式发布的 v0.1.0，需要正常工作的兼容 OOCore：

  • 服务端插件加载与基础接入。
  • 经权限检查的 /oo chat 入口提示，玩家和控制台均可使用；不会打开窗口或发送聊天消息。

当前发布版尚不适合作为完整聊天替代插件。开发分支已有聊天实现，不属于此处的已发布功能。

未实现功能 / Not implemented¶

  • 开发中、未发布：世界聊天、私聊、历史查询与撤回，以及频道、冷却、消息长度等配置；当前正式包不能使用这些能力。
  • 部分实现、待验收：管理禁言、权限保护与聊天插件冲突处理；多人交互与重启后的行为仍需完成验证。开发中的禁言目前不跨重载或重启保留。
  • 尚不可用：QQ 风格原生聊天窗口、会话未读提示和头像装扮；不能通过安装当前 OOChat 包获得 QQ 式交互。
  • 尚未完成产品联动：好友/群聊、跨服、邮箱附件、经济红包、会员与 OO 等级，以及 OOConsole 可视化配置；频道枚举或设计文档不代表对应服务已经接通。

未来计划 / Roadmap¶

  1. 优先完成可用聊天窗口：首个完整聊天正式版以 QQ 风格原生窗口为目标，包含会话列表、消息气泡、输入、世界聊天与私聊切换、历史和撤回显示。窗口依赖兼容的 OOEngine 与客户端能力，须完成真实客户端交互验证；不是将现有 v0.1.0 改称完整版本。
  2. 配置与创作优先：逐步让服主通过配置和 OOConsole 调整频道、通知及展示；以明确校验和安全回退保护现有服务器体验。
  3. 分阶段扩展社交能力：在聊天基础可用后推进好友、群聊、头像装扮和邮件，按正式接口接入相关服务。
  4. 会员与玩法联动：通过 OOVIP 联动 VIP/SVIP/MVP、会员 VID，加入独立于游戏等级的 OO 等级；经济红包通过经济插件接入，不由客户端决定资产或奖励。

以上是已确定的方向，不代表当前可下载功能，也不承诺具体发布日期。会员、红包等扩展不作为首个聊天窗口版本的必备功能。

安装¶

  1. 使用适配目标服务器的 Paper 环境及 Java，先安装并确认 OOCore 正常启动。当前最低已验证 OOCore 基线为 1.7.1；1.7.0 已撤回，请勿使用。
  2. 从正式 Release 获取 OOChat-0.1.0.jar，放入服务器的 plugins/ 目录。闭源二进制按授权范围提供；无法访问下载时联系作者，不使用来历不明的转载包。
  3. 完整重启服务器，确认 OOCore 和 OOChat 启用成功。
  4. 给测试账号授予 oochat.command.chat，执行 /oo chat 核对入口。

OOCore 是必需前置，但不要求未来版本号始终等于 1.7.1。OOChat 会检查平台协议和所需能力是否兼容，包括命令、调度、玩家与文本等支持；缺失能力时不要强行启用。Folia 的支持声明不代表任意版本均已实测，正式部署前应在相同环境的测试服验证。

OOConsole 为可选项；仅验证基础版时不必安装。OOEngine 和额外客户端 Mod 不是本版必要前置。

命令与权限¶

当前正式版¶

完整语法 参数与默认值 用途与最小示例 精确权限 执行者
/oo chat 无必填参数、无参数默认值；额外参数不产生聊天操作 返回入口提示 /oo chat；玩家输入 /oo chat，服务端控制台输入 oo chat oochat.command.chat 玩家或控制台；均须通过宿主权限检查，无玩家专属限制

根命令 /oo 由 OOCore 提供。v0.1.0 不提供可用的 send、history、recall、mute、unmute、status、doctor 或 reload 子命令，请不要给该版本套用开发版命令教程。当前命令没有注册别名，也不会打开聊天窗口。

权限¶

精确节点 对应功能 默认授予与继承
oochat.command.chat 使用基础 /oo chat 入口 OOChat 未声明该节点的默认值，也未注册父子权限；实际结果取决于服务器权限系统。未被其他插件覆盖时，Bukkit 对未注册节点通常为 OP 默认可用、普通玩家默认不可用。生产服请显式配置授权，不依赖 OP 推断。

OOChat v0.1.0 不提供 oochat.* 通配符或自动子权限继承；权限插件自行实现的通配符规则不属于 OOChat 的接口承诺。拒绝授权时命令不会执行入口处理。安装 LuckPerms 的服务器可按其规则给所需玩家或权限组授予 oochat.command.chat；OOChat 不额外维护一套用户组。

变量与占位符¶

当前版本暂无对外变量/占位符。

类型 v0.1.0 支持情况 可用位置与返回示例
PlaceholderAPI / PAPI 没有注册 OOChat expansion；安装 PAPI 不会新增 OOChat 占位符 无
消息模板变量 没有正式提供可编辑的消息模板变量接口 无
UI 绑定变量 没有正式提供玩家窗口或公开 UI 绑定接口 无
配置替换变量 没有用户配置替换变量接口 无

请勿把内部字段、构建时版本替换或开发版设计当成可直接填写的占位符。

后续版本（未发布）¶

开发中的命令包括消息发送、历史查询、撤回、禁言/解除禁言及配置诊断、重载；准确语法与权限将在对应正式版本发布时补充。当前管理权限与异步命令仍在收口验收，不建议以开发包替换生产聊天管理。

配置¶

v0.1.0 没有用户可编辑的聊天 YAML 配置，也不会生成下列开发版配置。 无需手动创建 config.yml 期待启用聊天功能；插件描述文件不是服主配置文件。

后续版本计划在 plugins/OOChat/ 提供以下带中英说明的配置：

文件 用途 预期生效方式（开发中）
config.yml 全局消息长度与速率限制 校验后重载
channels.yml 频道权限、冷却与长度限制 校验后重载
moderation.yml 撤回、禁言和保护权限 校验后重载
retention.yml 历史保留规则 校验后重载
storage.yml 存储后端、数据路径及完整性策略 后端、路径及完整性策略变化需重启

下面只是未发布配置格式预览，不适用于 v0.1.0：

# config.yml：消息最大 Unicode 码点数 / Maximum message code points
max-message-codepoints: 2048
# 突发消息数和补充周期（毫秒） / Burst capacity and refill period (ms)
rate:
  burst-capacity: 5
  refill-period-ms: 1000

开发版以完整校验后再应用配置为目标，非法新配置不应覆盖旧配置。当前 SQLite 未提供随包可用驱动，不能宣传为可直接启用的生产存储。当前开发中的禁言为内存态，重载或重启会清除，不能用于需要持久封禁记录的生产管理。

升级与回滚¶

  • v0.1.0 用户应等待后续正式发布，不把 SNAPSHOT 当稳定升级包。
  • 升级前停止服务器，备份插件 JAR、plugins/OOChat/（若存在）和相关存储；保留配套 OOCore 版本信息。
  • 首先在测试服确认命令、聊天投递和重启后的数据行为，再迁移生产服。
  • 数据格式变化时按对应版本说明迁移；不能直接用旧插件覆盖新格式数据。需要回滚时恢复同一次备份中的插件和数据。

版本状态¶

本页按正式下载版与未发布功能分别说明。当前正式版仍为 v0.1.0；后续聊天核心正在验收，不因开发分支存在实现便视为公开可用。

已知问题¶

  • v0.1.0 不提供完整玩家聊天闭环，无法替代现有聊天插件。
  • 尚无正式可用的 QQ 风格界面和 OOConsole 聊天配置工作区。
  • 后续版本的管理权限、冲突聊天监听器及多人重启场景仍需完成验收；开发版不建议用于生产服。
  • 与其他聊天插件共同使用前应测试消息取消、重复广播和权限拒绝行为。

Java 21 兼容计划¶

Java 21 平台兼容线已列入计划，当前 OOChat 发布版不能据此视为支持 Java 21。目标先覆盖 Paper 1.20.5/1.20.6 和 1.21 系列的 API 分界，逐项验证后公布实际支持范围；更早 1.20.x 后续核验。该兼容线依赖正式兼容的 OOCore，窗口功能还需要相应 OOEngine 与客户端支持。

现有 Java 25 / Paper 26.x 方向继续保留；26.x 服务器不能改用 Java 21 运行。Folia 需独立验收，不因 Paper 通过而自动列为支持。请以对应正式发布版的明确兼容说明选择环境，不要仅修改 Java 版本后投入生产。
