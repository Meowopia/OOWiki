# Meowopia · Cat Crests 像素徽章

以用户确认的 Cat Crests 设计图为准：统一黑猫头轮廓、粉色耳朵、蓝色项圈和金铃，中央通过功能符号区分插件。

| 产品 | 中央符号 |
| --- | --- |
| OOCore | 青色线框方块 |
| OOEngine | 紫色齿轮 |
| OOConsole | 蓝色管理窗口 |
| OOGame | 橙色手柄 |
| OOMusic | 洋红双音符 |
| OOBrowser | 青绿地球网格 |
| OOChat | 绿色双对话框 |
| OOReforge | 铜红锤与铁砧 |
| OOVIP | 金色皇冠 |

每款包含独立透明 `source.png` 和 `logo-32.png`、`logo-64.png`、`logo-128.png`、`logo-256.png`、`logo-1024.png`。通过 `scripts/export-pixel-icons.ps1` 最近邻导出，校验摘要见 `assets.json`。

Wiki 列表使用 128px 文件显示为 64px，产品页使用 256px 文件显示为 160px。保持透明背景、方形画布及完整徽章，不拉伸裁剪。此套取代误用的 Pixel Companions 全身黑猫图标；产品版本和发布状态以文档为准。
