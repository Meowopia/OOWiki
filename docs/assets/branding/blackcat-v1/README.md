# 喵托邦 / Meowopia 黑猫品牌资源

九个产品分别使用独立绘制的动作与道具，不以换色区分产品。黑猫、蓝眼、蓝项圈、单金铃和卷尾是共同识别特征。

- `logo-1024.png`：1024×1024 RGBA 高清图标，真实透明背景。
- `logo-32.png`、`logo-64.png`、`logo-128.png`、`logo-256.png`：小尺寸 PNG。
- `logo-256.webp`：网页卡片与首页使用的透明图标。
- `banner-1200x630.png`：产品介绍横幅。
- `banner-1200x630.webp`：网页优化横幅；应完整显示，不裁切标题或角色。
- `assets.json`：公开资源尺寸、大小与 SHA256 清单。

这些是栅格图片，不是矢量文件。横幅仅表达产品定位，不代表规划功能已经实现；版本与可用性以产品正文为准。品牌图片的展示不改变各产品的软件许可或源码公开边界。

OOGame 使用实际游玩握法，按钮面朝向猫；OOConsole 表现图形化管理与配置，不使用音频调音台；OOBrowser 横幅使用完整地球仪，避免错乱的线框球体。
