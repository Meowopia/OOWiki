# 博客与创作

[打开 zkonikishi 的博客](https://blog.meowopia.com/)，阅读技术记录、生活随笔和 Meowopia 项目背后的过程。

## 阅读

公开文章不需要登录。可以通过文章列表、分类与搜索找到内容；以博客当前展示的文章为准。

## 作者登录

作者从[博客 OO 登录入口](https://blog.meowopia.com/auth/oo/login)进入，完成 OO 登录后返回博客。只有获得写作授权的账号可以进入编辑与发布功能。注册 OO 账号不会自动成为这个个人博客的作者。

## 个人空间与博客的区别

希望拥有自己的介绍、动态和日志，可以使用 [OO 空间](oo.md)。这里的博客由作者维护；两者共享 OO 登录体系，但内容与权限分别管理。

图片上传和文章发布若暂时不可用，请保留自己的原稿，并通过[社区](community.md)反馈。
