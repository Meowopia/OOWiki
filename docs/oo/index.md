# OO 账号与空间

OO 是连接 Meowopia 项目的统一账号，也提供个人空间、动态和日志等社区入口。

## 注册账号

1. 打开 [OO 注册](https://oo.meowopia.com/register)。
2. 填写邮箱，点击发送验证码，检查收件箱和垃圾邮件。
3. 在注册页面填写验证码和密码，再次输入密码确认。密码框旁可切换显示与隐藏。
4. 完成注册后，到 [OO 登录](https://oo.meowopia.com/login) 使用邮箱或 OO 号登录。

验证码和密码只在账号页面输入，不要发到社区或文档反馈中。

## 使用个人空间

登录后从[账号页](https://oo.meowopia.com/account)进入[管理我的空间](https://oo.meowopia.com/space)，填写介绍、发布内容，并查看自己的公开主页。也可以先到[空间广场](https://oo.meowopia.com/explore)看看其他人的公开内容。公开发布前请确认内容适合展示。

## 忘记密码

使用[找回密码](https://oo.meowopia.com/reset)页面，通过邮箱验证码设置新密码。重置密码会撤销旧的登录会话与项目授权。

## 登录其他项目

从对应项目的登录按钮进入 OO 授权流程，完成后返回该项目。博客写作和后台管理需要额外授权；普通账号没有管理员权限。

## KOOK 社区

可以直接使用[服务器邀请](https://kook.vip/DYfU86)加入社区。加入服务器与关联 OO 账号是两件事；是否能够绑定，以 OO 账号页面实际提供的入口为准。

更多信息见 [OO 隐私说明](https://oo.meowopia.com/privacy)。
