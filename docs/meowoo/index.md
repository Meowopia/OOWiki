# Meowoo · 跨平台个人影音应用

![戴薄荷绿猫耳耳机的 Meowoo 角色与多设备影音场景](../assets/community/meowoo-banner-chibi-v5.png)

Meowoo 是基于 Flutter 开发的跨平台个人影音应用，目前处于 **0.3.0-dev.1 早期开发预览**，暂无正式发行安装包。上图为项目插画，实际界面与平台支持情况以当前版本说明为准。

## 项目与安装包

从 [Meowoo 官网](https://meowoo.meowopia.com/)查看最新介绍和预览进度，也可以访问 [Meowoo 项目仓库](https://github.com/Meowopia/Meowoo)。当前没有正式安装包；后续测试与正式发行以官网公告为准。

## OO 账号与云同步

支持相关功能的测试版本可通过 OO 账号进行登录授权。请从应用内部发起登录，在 OO 页面完成后返回应用。

云同步服务已经接入独立存储与 OO 授权校验。服务可访问不等于各平台的开发预览均已完成端到端验收；同步功能以当前版本的说明和实际可用状态为准。

同步不等于上传媒体文件。不要把敏感链接、访问凭据或个人密钥放进公开反馈；可同步内容以应用提供的设置与确认项为准。

## 遇到问题

反馈时说明设备类型、操作系统、应用版本和复现步骤。不要提交密码、验证码或授权令牌。可以到[社区与帮助](../community/index.md)查看反馈入口。
